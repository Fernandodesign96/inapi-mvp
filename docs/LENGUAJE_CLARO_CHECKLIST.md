# Checklist de lenguaje claro — Portal INAPI

Referencia para revisar cada pantalla del portal. Total: **39 criterios**.

| Sección | Criterios |
| --- | --- |
| A. Estructura | 5 |
| B. Lenguaje claro | 7 |
| C. Redacción y concisión | 7 |
| D. Ortografía y formato | 7 |
| E. Objetividad y fiabilidad | 4 |
| F. Enlaces | 5 |
| G. Datos personales y PI | 3 |
| H. Archivo | 1 |

---

## A. Estructura y organización del contenido

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| A1 | El mensaje más importante está en la parte superior | Lee solo el primer párrafo: ¿se entiende el propósito sin leer el resto? |
| A2 | Pirámide invertida | Lo más importante arriba, los detalles abajo |
| A3 | Secciones con encabezados informativos | No hay bloques de texto continuos sin títulos |
| A4 | ≤110 palabras por sección | Contar palabras del bloque continuo más largo |
| A5 | Solo información necesaria para completar la tarea | Sin relleno institucional ni marketing |

## B. Lenguaje claro

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| B1 | Voz activa | Buscar “se debe”, “será”, “deberá” → reescribir en activa |
| B2 | Palabras comunes | Definir jerga burocrática en contexto |
| B3 | Siglas definidas la primera vez | Ej.: “Tratado de Cooperación en materia de Patentes (PCT)” |
| B4 | Evitar abreviaturas y extranjerismos | “empresa emergente” en vez de “startup” |
| B5 | Tono positivo | Indica lo que se puede hacer |
| B6 | Tuteo, amable y consistente | Sin mezcla de registros en la misma pantalla |
| B7 | Sin frases de relleno | Sin “valor agregado”, “buenas prácticas”, “de oficio” |

## C. Redacción y concisión

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| C1 | Orden sujeto-verbo-predicado | Revisar oraciones largas |
| C2 | Presente simple | “Este formulario acredita…” vs “acreditará…” |
| C3 | Oraciones simples (≤30 palabras) | Una idea por oración |
| C4 | Un párrafo = una idea | Separar ideas distintas |
| C5 | Párrafos cortos | <8 líneas escritorio, <4 móvil |
| C6 | Resumen al inicio (textos largos) | Solo en artículos extensos |
| C7 | Requisitos en infinitivo | “Ser mayor de 18 años”, “Enviar la solicitud” |

## D. Ortografía, gramática y formato

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| D1 | Corrector ortográfico + precisión conceptual | Sin errores marcados ni de concepto |
| D2 | Puntuación y concordancia | Puntos seguidos sobre comas intercaladas |
| D3 | Espacio entre párrafos | Verificar visualmente |
| D4 | Texto alineado a la izquierda | No centrado ni justificado (salvo títulos hero) |
| D5 | Listas para enumeraciones | No textos corridos con comas |
| D6 | Negritas para palabras clave | Máximo una por párrafo extenso |
| D7 | Sin frases solo en mayúsculas | “Ingresa aquí”, no “INGRESA AQUÍ” |

## E. Objetividad, autoría y fiabilidad

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| E1 | Contenido objetivo | Sin adjetivos calificativos (“excelente”, “moderna”) |
| E2 | Autoría identificable | INAPI visible en encabezado o pie |
| E3 | Fecha de actualización visible | No reemplazar con solo copyright |
| E4 | Título fiel al contenido | H1 y `<title>` específicos |

## F. Enlaces y referencias

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| F1 | Nombre del enlace = nombre del destino | Coherencia texto/href |
| F2 | Enlaces descriptivos | No “Haz clic aquí”, “Ver más” genéricos |
| F3 | Botones significativos | “Confirmar envío”, no “Aceptar” |
| F4 | Documentos con formato y peso | “Manual (PDF, 345 KB)” |
| F5 | Enlaces fuera del cuerpo de lectura | Al final del párrafo o como CTA |

## G. Datos personales y propiedad intelectual

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| G1 | Sin datos personales en HTML estático | RUT, nombre, contacto solo vía sesión |
| G2 | Derechos ARCO visibles | Enlace en política de privacidad |
| G3 | Condiciones de uso publicadas | Copyright o licencia CC con año vigente |

## H. Archivo y versionado

| ID | Criterio | Cómo verificar |
| --- | --- | --- |
| H1 | Versiones antiguas rotuladas | “Requisitos 2024 (archivo)” |

---

*Usar este checklist en cada PR de contenido. Las pantallas del portal deben cumplir los 39 criterios antes de considerarse listas para revisión con usuarios.*
